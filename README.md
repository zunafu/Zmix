🎵 Discord Music Bot

A simple and lightweight Discord music bot built with JavaScript. It provides essential music controls for playing songs, managing queues, and controlling playback directly from your Discord server.

✨ Features
▶️ Play — Play music in a voice channel
⏸️ Pause — Pause the current song
▶️ Resume — Resume paused music
⏭️ Skip — Skip the current song
⏩ Skip To — Skip to a specific song in the queue
📜 Queue — View the current music queue
🔀 Shuffle — Randomize the queue
⏹️ Quit — Stop playback and leave the voice channel
ℹ️ Info — Display information about the current song or bot

📥 Installation
1. Clone the Repository
`git clone <repository-url>
cd <project-folder>`

2. Install Dependencies

Install the required dependencies using npm:

`npm install`

3. Configure the Bot

Create a .env file in the root directory of the project:

`DISCORD_TOKEN=your_bot_token
CLIENT_ID=your_client_id`


Replace the placeholder values with your Discord bot credentials.

4. Start the Bot

Run the bot with:

`node index.js`

🚀 Usage

Once started, the bot will connect to Discord and be ready to receive music commands.

Make sure the bot has been invited to your Discord server with the appropriate permissions, including access to voice channels and send messages.

🎶 That's It!

Your Discord music bot should now be online and ready to play music! 🎵
