🎵 Discord Music Bot

A simple and lightweight Discord music bot built with JavaScript. It provides essential music controls such as playing songs, managing a queue, pausing, resuming, skipping, shuffling, and stopping playback.
✨ Features

    ▶️ Play — Play music in a voice channel
    ⏸️ Pause — Pause the current song
    ▶️ Resume — Resume paused music
    ⏭️ Skip — Skip the current song
    ⏩ Skip To — Skip to a specific song in the queue
    📜 Queue — View the current music queue
    🔀 Shuffle — Randomize the queue
    ⏹️ Quit — Stop playback and leave the voice channel
    ℹ️ Info — Display information about the current song/bot
    
📥 Installation
1. Clone the repository
git clone <repository-url>
cd <project-folder>

2. Install dependencies
npm install

3. Configure the bot

Create a .env file:

DISCORD_TOKEN=your_bot_token
CLIENT_ID=your_client_id

4. Start the bot
node index.js


That's it! 🎵 Your Discord music bot should now be online.
